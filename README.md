#  Brasa Grill

A modern, responsive restaurant website built from scratch using **HTML, CSS, and JavaScript**.

##  Overview

**Brasa Grill** is a modern restaurant website designed to provide a visually engaging and responsive user experience.

The website combines a dark, elegant aesthetic with warm accent colors to create a premium restaurant atmosphere.

This project was developed from scratch with a focus on:

- Responsive web design
- Clean and structured UI
- CSS animations and transitions
- Interactive JavaScript elements
- Mobile-friendly navigation
- Modern restaurant website layout

## Features

- Responsive navigation
- Mobile hamburger menu
- Hero section with call-to-action buttons
- Interactive menu sections
- Signature dishes section
- Why Choose Us section
- Private dining section
- Customer testimonials
- Table reservation section
- Newsletter section
- Responsive footer
- CSS hover effects and transitions
- Responsive layouts for different screen sizes
- JavaScript-powered interactions

## Technologies Used

- **HTML5** – Website structure and semantic markup
- **CSS3** – Styling, layouts, animations, and responsive design
- **JavaScript** – Interactive functionality
